ESP32 node measurements

Node IDs, source IPs, packet freshness, measured RSSI, packet rate, sequence, and CSI amplitudes are shown in the live CSI dashboard.

The connected nodes send 2.4 GHz CSI frames. Antenna layouts, radio controls, and host resource usage are not measured by this page.

CSI receiver flow

This setup receives ESP32 packets, validates their wire format, and displays measured packet and radio values.

  1. ESP32 nodes send raw CSI over the local Wi-Fi network.
  2. The receiver checks node ID, frequency, dimensions, RSSI, and exact packet length.
  3. The dashboard reports packet age, sequence, rate, RSSI, and I/Q amplitude magnitude.
  4. Human presence inference is not validated by this dashboard.
